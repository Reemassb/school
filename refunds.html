Delivery

Delivery is instant and digital. Your access code arrives by email from Gumroad the moment payment goes through, along with the link to the app. Nothing is posted to you.

If the email hasn't arrived within a few minutes, check your spam folder first — then write to us and we'll send the code directly.

Refunds

Because each code creates illustrations that cost us money the moment they're generated, we can only refund a code that is completely unused.

  • Unused code — full refund, within 14 days of purchase, no questions asked.
  • Partly used code — we can't refund the credits already spent, but do write to us; if something went wrong we will usually make it right.
  • Something broken — if the app failed, a page generated incorrectly, or you were charged twice, tell us and we'll fix it or refund you.

Before you buy

Two things worth knowing, because they cause most of the problems we see. You need one clear, front-facing photo in good light with the face filling most of the frame. And the app must be opened in Safari or Chrome, not inside Instagram or Gmail.

How to ask

Email reemafahmi@gmail.com with your Gumroad order number. We answer within two working days.

الاسترجاع

لأنّ كلّ رمز يُنشئ رسومات تترتّب عليها تكلفة فور إنشائها، لا يمكننا استرجاع قيمة إلّا لرمزٍ لم يُستخدَم إطلاقًا.

  • رمز غير مستخدَم — استرجاع كامل خلال ١٤ يومًا من الشراء، دون أسئلة.
  • رمز مستخدَم جزئيًّا — لا يمكننا استرجاع قيمة الرسومات المستهلَكة، لكن راسلينا؛ فإن كان هناك خلل فسنعالج الأمر عادةً.
  • خلل تقنيّ — إن تعطّل التطبيق، أو خرجت صفحة بشكل خاطئ، أو خُصم المبلغ مرّتين، فأخبرينا لنصلح الأمر أو نعيد المبلغ.

قبل الشراء

أمران يستحقّان الانتباه، لأنّهما سبب معظم المشكلات التي تصلنا: تحتاجين إلى صورة أمامية واضحة بإضاءة جيدة والوجه يملأ معظمها. ويجب فتح التطبيق في Safari أو Chrome، لا داخل إنستغرام أو Gmail.
