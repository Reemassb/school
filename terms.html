What you are buying

One access code. One code creates one complete storybook: a character page plus nine story pages, downloadable as a printable PDF. Choosing a second story, or making a book for a second child, needs a second code.

Your code

Your code carries a fixed number of illustration credits. Each page uses one credit. Once a code is attached to a book, it stays with that book. Codes are for your own family or classroom use — please don't share or resell them.

Using your book

The finished book is yours. Read it, print it, and give copies to family. What you may not do is sell it, redistribute it, or use it commercially.

How the illustrations are made

The pictures are generated by an AI image model from the photo you upload. Each book is different, and the likeness will not be exact — it is a friendly cartoon of your child, not a portrait. Occasionally a page comes out imperfectly; if something is genuinely wrong, write to us.

Please use a normal browser

Open the app in Safari or Chrome. The built-in browsers inside Instagram, Facebook and Gmail block PDF downloads and clear their storage without warning, which can lose a finished book.

Availability

This is a small independent product. We aim to keep it running and available, but we can't promise uninterrupted service.
